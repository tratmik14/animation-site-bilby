# Билби

Адаптивный учебный фан-сайт о короткометражном мультфильме DreamWorks Animation 2018 года. Восемь кадров, история героев, просмотр изображений с клавиатуры и мини-приключение из трёх испытаний.

## Открыть
Откройте index.html в браузере. Библиотеки и сборка не нужны. Все кадры и шрифт сохранены локально. История и галерея доступны без JavaScript; интерактивная игра требует его включения.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save. Адрес после публикации: https://tratmik14.github.io/animation-site-bilby/
